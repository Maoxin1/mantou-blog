网站流量 / Website analytics

访问量和性能数据保存在 Cloudflare 后台，需要登录拥有此站点权限的账户。博客页面不会展示统计数据。

Traffic and performance data are available in your private Cloudflare dashboard. Sign in with the account that owns this site.

打开统计后台 / Open analytics → 选择 mantou-blog.pages.dev。页面路径以 /en/ 开头的是英文内容；/p/ 是中文文章，/works/ 是中文作品。 Select mantou-blog.pages.dev. English pages start with /en/. Chinese articles use /p/ and projects use /works/.

建议查看：浏览量、访问次数、热门页面、来源、设备和加载性能。访问次数不等于去重访客人数；当前统计不包含按钮点击或订阅转化。

Review page views, visits, popular pages, referrers, devices, and loading performance. Visits are not unique visitors. Button clicks and subscription conversions are not tracked.
