      添加到安卓手机桌面

      用手机 Chrome 打开本页并完成本人登录。在浏览器菜单中选择“安装应用”或“添加到主屏幕”，再从桌面的“网站数据”图标进入。安装方式取决于手机和浏览器；没有安装选项时，可以继续在浏览器查看。

      查看数据需要联网；登录过期时需重新登录。添加到桌面不会授予报表访问权限。

      指标与数据说明

      Website analytics。访问量保存在 Cloudflare 后台。Visits 不是独立访客人数；当前统计不包含按钮点击或订阅转化。

      Visits are not unique visitors. Button clicks and subscription conversions are not tracked.

      客户端统计可能漏计，列表和服务商抽样可能影响结果；不承诺每次访问精确入库。上期为 0 时，展示增减次数，不计算百分比。
