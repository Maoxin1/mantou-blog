网站流量 / Website analytics

基础访问量与性能数据保存在 Cloudflare；来源、文章、作品与订阅意向的行为漏斗将在配置 Umami Website ID 后开始采集。两个后台都需要本人登录，不在博客公开展示数据。

Cloudflare holds traffic and performance data. Source-to-article-to-project or subscription-intent funnels begin collecting after an Umami Website ID is configured. Both dashboards require your own login.

打开统计后台 / Open analytics →

打开行为漏斗后台 / Open behavior dashboard →

选择 mantou-blog.pages.dev。页面路径以 /en/ 开头的是英文内容；/p/ 是中文文章，/works/ 是中文作品。 Select mantou-blog.pages.dev. English pages start with /en/. Chinese articles use /p/ and projects use /works/.

Cloudflare 可查看浏览量、访问次数、热门页面、来源、设备和加载性能。Umami 启用后可查看作品打开、RSS 意向与邮件表单提交；表单提交不等于订阅成功。

Cloudflare shows page views, visits, popular pages, sources, devices, and performance. Once enabled, Umami shows project opens, RSS intent, and email form submissions. A submitted form does not prove a confirmed subscription.
