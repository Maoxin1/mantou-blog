# 好习惯的生长图与练习入口

这次把用户已选定的黑白粒子图用于个人练习入口，以及 `/now/`、关于页的独立图片区。它表达的是几个靠近的好习惯持续生长，能力逐渐交织并带来新的可能。

## 页面

- `/practice/` 与 `/en/practice/`：顶部保留完整横图，下方提供投研、英语、身体三个入口。入口链接现有文章或实践案例；各方向附带可复制的 AI 练习提问。
- `/now/` 与 `/en/now/`：在原有方向清单前增加图片说明和练习入口。
- `/about/` 与 `/en/about/`：在介绍后增加图片说明和练习入口。

继续使用现有暖纸、墨色、陶土色和字标；黑白图限于图片本身。原首页的书本插画、原有进展与复核日期保持不变。不生成收益、打卡或进度数据。

## 素材与行为

`static/images/growth/` 包含 800×450、1600×900 的 WebP，使用响应式 `srcset`，明确图片尺寸以避免布局跳动。练习页优先加载图片，其他页面延迟加载。

页面的主要内容、展开提问和导航不依赖 JavaScript。安全上下文支持 Clipboard API 时才显示复制按钮；复制失败有文字提示，仍可手动选择提问。未引入新依赖、登录、个人数据保存或外部请求。

## 验收

核对中英页面的现有链接，确认移动端没有横向溢出，图片完整显示，主题切换后的文字可读，复制按钮的内容与对应提问一致。使用原仓库的 Hugo 构建与 Validate 发布门槛。
