# mantou 视觉改版

2026-10-04 验收后推进的 v3：01 软团字、P1 圆头小人、暖橙扁平漫画。首页使用翻书场景、投资推荐插画与阅读/实践文字行；正文采用干净的阅读栏。人物保持椭圆头、两只眼睛和简洁四肢，不添加嘴、鼻子、头发或服装。

## 页面与素材

首页文案为“知不足而奋进，望远山而前行。”及“记录投资判断、读书所得，以及亲手做过的项目。”。首屏不放行动按钮；精选之后保留最近更新、阅读和精选导航。分类按钮只筛选当前精选的三篇文章，通过 aria-pressed 表达状态；禁用 JavaScript 时全部文章仍可访问。筛选后使用阅读锚点会恢复可见内容。

推荐文章是《别再误解泡泡玛特了！》，阅读行是《把阅读变成作品：我的五本书交付标准》，实践行是《我不想再把个人博客做成作品陈列柜》。中英文均读取对应的现有文章；原始正文和译文没有改写。作品、最近更新、照片、订阅、反馈、搜索、RSS、CMS、PWA 和短地址继续沿用原有实现。

`static/images/identity/comic-*-v3-*.webp` 是新素材，旧图保留。素材通过内置图像生成工具绘制；生产文件只做等比缩放和 WebP 编码。翻书图使用已验收的 P1 场景；研究图提示为“一个 P1 小人蹲下，手持放大镜检查暖橙色开箱中的星形卡片，粗黑线、奶油白、局部印刷颗粒、无文字和水印”；纸桥沿用已验收的新漫画版本。首页使用 srcset、明确图片尺寸和指纹脚本；站点分享图同步为暖橙漫画。

`data/home.yaml` 维护精选入口；`layouts/index.html` 与 `assets/js/home-filters.js` 提供首页和渐进增强筛选；`layouts/posts/single.html` 增加桌面目录与阅读文章的小插画；`assets/css/_visual-identity.scss` 维护响应式和深色模式。字标继续使用已选 SVG，不以普通字体重画。

## 阅读与响应式

暖纸 #fffaf1、墨色 #292824、陶土 #a84e32、次级文字 #6b6258；深色模式使用暖灰和浅陶。正文不叠加纹理。文章阅读栏最多 700 px，桌面正文 18 px / 1.9、手机 17 px / 1.9，标题字重 600，长标题自然换行并使用 text-wrap: balance。桌面目录在 1025 px 及以上显示在右侧；小屏保留可展开目录。没有目录的短文保持居中。

字体调用 Noto Sans SC → PingFang SC → Microsoft YaHei → Noto Sans CJK SC → sans-serif，不增加外部字体请求。跨系统字形可能有细微差别，完整字体许可见 NotoSansSC-OFL.txt。降低动态效果、键盘焦点、跳到正文、主题切换与粘性导航锚点偏移均沿用原有规则。

## 验证与发布

使用 Hugo Extended 0.154.5、Pagefind 1.5.2 和仓库 Validate 流程。新增验收覆盖 320/390/1366 px 首屏完整标题、双语筛选、筛选后锚点导航、无 JavaScript 阅读、桌面目录跳转与手机目录。

本地 97 项 Python 检查、206 篇文章和译文校验、39,415 个内部引用、短地址、作品、SEO、运行时资源和双语首页结构检查通过，两个 npm 依赖审计均为 0 漏洞。实际 Chromium 截图检查了桌面、手机、双语、文章和深色页面，均未产生横向溢出或页面运行时错误。

本地 agent-browser 的守护进程因环境禁止绑定 socket 无法启动，实际截图及交互验收改用 Playwright Chromium。完整浏览器套件还包含外部 CMS CDN 和线上旧地址跳转，合并必须等待 PR 的完整 Validate 成功；不移除测试或降低发布门槛。可用 `MANTOU_CHROMIUM_PATH=/path/to/chromium npm run test:e2e` 指定本地浏览器，CI 继续使用锁定的 Playwright 浏览器。

用户已明确授权部署和合并。通过独立 PR 合并到 main 后，现有 Validate / Deploy Pages 自动发布；发布流程与权限不作修改。
