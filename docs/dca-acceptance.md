# 定投 · 长期手记

## 功能与发布承诺

面向博客读者，沿用已确认的 C 版暖纸手记风格。在 `/dca/` 体验 BTC/USDT 月度定投历史回测、独立的复利假设模拟、每 60 秒尝试更新的行情。首页和导航提供入口，保留已合并的首页投资强调移除结果。英语入口明确引导至中文工具。

## 验收与停止条件

- 读者能调整月度投入、起止月份、费率，分清投入、持仓价值和浮动盈亏，并展开逐月核对。
- 历史数据注明交易对、来源、UTC 月线范围；费用是用户假设，不伪装成交易所实际费率。按月初开盘买入、月末收盘估值，仅包含完整月份。断网使用随版本发布的数据，明确截止日期。
- 复利使用有效年收益率转等效月率，月末追加，允许零与负收益；本金和收益分别展示。
- 行情只访问无鉴权的公开行情接口。可见页每 60 秒尝试刷新，后台暂停，超时 8 秒；离线、失败、旧时间戳和异常响应不得显示“实时”。不保存账户信息，不含买卖功能。
- 桌面和手机实际浏览器检查，零输入、反向日期、手续费、缺失月份、旧行情、失败后恢复均有覆盖。
- 遵循现有 PR → Validate → main → Validate → Deploy Pages 门禁；不调整部署权限或降低检查。

## 数据与限制

初始快照为 2018-01 至 2026-09 的 105 个完整月，2026-10-08 读取。来源：Binance Spot API `klines`，BTCUSDT，1M，UTC。`ticker/24hr` 单独提供最新报价；其时间不用于改写历史期末估值。USDT 不等同于美元法币，未计汇兑、税费和滑点，也未扣期末卖出费。月末亏损统计不代表月内最大回撤。

公开行情端点：`https://data-api.binance.vision/api/v3/`。页面打开时更新完整月线，接口不可达时保留附带快照。页内不提供跨交易所静默替换，避免交易对和口径混淆。外部接口可能因读者网络不可达，此时显示失败和最近数据时间，提供手动重试。

可核查文档：https://github.com/binance/binance-spot-api-docs/blob/master/faqs/market_data_only.md
