## 缺口处理顺序

先处理 EC-ANL-001/003/004/009/016/019：它们决定本人能否看到、能否解释结果及何时可以验收。EC-ANL-010/013/014/021/022 决定接入正确与原体验/隐私边界；已有局部证据不能替代缺失场景。其余先保留按风险触发，不为凑维度实现新能力。

本阶段只建立记录。阻断分级、稳定行为 ID 与待采纳范围选择见[功能规范](analytics-v1.md)。若后续证据暴露故障，再从缺口选最小修复范围；不会因表中出现某风险自动立项所有测试、迁移、重试或安全功能。
