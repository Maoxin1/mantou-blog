关键正常验收：本人完成身份授权后，服务器读取真实本站两个期间；页面展示一致口径的指标和图表，能明确看到时间/增减。关键失败：伪造/缺失/过期 JWT 拒绝且不调用数据源；缺少配置/接口错误不填零；未登录不能读取 API；失败后可重试，旧数字不冒充新结果；博客公开阅读保持可用。

外部 SPEC GAP：与后台同窗口/筛选的数值比对、采样导致的聚合差异解释、新版发布后本人网页/API身份与真实数据显示，以及实际手机流程。账户 schema、只读权限及 bot=0 实际查询已经验证，见[真实读取记录](../implementation/analytics-overview-20261009/real-data.md)。技术读取成功不能关闭人工比对或线上权限验收；未知误差容忍度不写成验收标准。
