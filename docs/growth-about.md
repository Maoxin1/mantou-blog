# 关于页的生长粒子图

用户选择只推进关于页。图片放在自我介绍之后、写作与作品之前，配一小段说明，表达几个持续的好习惯如何延伸、交织，逐渐带来新的能力与可能。图片旁的链接进入已有作品页。

中英关于页使用同一个布局和图片。图片区域沿用暖纸背景、墨色文字、陶土色链接；完整横图保持 16:9，手机上先显示图片，再显示说明。

`static/images/growth/` 包含 800×450、1600×900 的响应式 WebP，明确图片尺寸并延迟加载。页面没有新增脚本、依赖或个人数据保存。

学习投研主页、练习提问与近况页图片区均已从草稿移除。原有首页、近况清单及其复核日期继续使用原实现。

使用 Hugo 严格构建、内部链接检查与实际 Chromium 核对桌面、手机、中英及深色显示。完整 Validate 是现有发布门槛，本次不修改发布流程。
