| A 快捷入口、沿用现有报表 | 直接进入固定站点的最近 7/30 天报表，少选一次站点；图表显示随时间变化，页面/来源继续用原界面 | 现在可收藏站点报表；后续可改善现有入口的快捷按钮。深链接按已观察参数构造，须在本人后台确认实际采用筛选，不能仅由字符串正确判通过。无新增数据接口/登录系统 | 先做 A，低投入，适合主要痛点是寻找入口与选条件。只能改善入口，不能重新安排服务商界面或承诺其未核实的上期比较 |

两条站点深链接使用此前观察的 siteTag、excludeBots=Yes、time-window，移除 path。不是新接口或公开分享 URL；仍依赖 Cloudflare 有权会话。未在本次私有后台执行导航，不将候选按钮写成已上线。

官方 [Web Analytics 筛选说明](https://developers.cloudflare.com/web-analytics/configuration-options/filters/)支持时间调整与图表/细分；[维度说明](https://developers.cloudflare.com/web-analytics/data-metrics/dimensions/)支持页面/来源维度。官方 [Custom Dashboards](https://developers.cloudflare.com/analytics/custom-dashboards/)描述跨数据集图表，但当前账户是否能用它读取同口径的 Web Analytics RUM 尚未证明；不能把此前 HTTP 流量概览的 Requests 直接替代 PV。
