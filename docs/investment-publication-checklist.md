# 投资作品发布前检查单

这份检查单用于落实公开边界，不用于证明投资判断正确。机器检查只能发现少量高风险表达，发布者仍需逐项人工复核。

## 账户与身份信息

- [ ] 未公开账户总收益或可据此反推出总收益的数据；
- [ ] 未公开账户金额、投入本金、持仓金额或资产余额；
- [ ] 未公开当前仓位、持仓比例或可反推出仓位的交易数量；
- [ ] 截图、附件、图片元数据中没有账户号、金额、仓位或其他身份信息。

## 具体标的与时点

- [ ] 具体标的已经到达阶段复盘或完全退出后的公开时点；
- [ ] 若尚未到公开时点，正文、标题、链接和图片均已匿名或延迟；
- [ ] `disclosure` 与正文实际公开程度一致，不用标签代替检查。

## 证据与表述

- [ ] 公司财务数据、市场数据与个人账户数据已明确区分；
- [ ] 已区分事实、公司指引、外部估计、个人假设和事后推论；
- [ ] 已写明失败条件、当前限制与下一步判断；
- [ ] 完成上述检查后，才将 `privacy_reviewed` 设为 `true`。

CI会阻止未完成隐私复核的投资作品，并提示少量高置信度风险表达；它无法理解全部语境，也不能代替发布者的最终审阅。
