# 博客首页与阅读体验 1.1

本轮目标：让首次访问者看见博客的内容范围，让回访者直接找到新文章，并让不同类型的内容保留各自的写法。

## 本次范围

- 首页自动显示最近 5 篇已发布文章；精选内容只在 `data/home.yaml` 维护路径和类型，标题、摘要取自原文。
- 将一篇生活日记、一件身体实践和一篇思考文章放在精选区；工具另设实际界面预览与使用入口。
- 作品列表使用每件作品自己的 `list_summary`，没有该字段时退回 `description`，不再按 `work_type` 套用固定故事。
- 作品详情恢复正文目录；身体记录的体重曲线移到正文前，工具详情展示实际界面截图。结果、证据与限制继续可一键跳转。
- 顶部导航改为文章、作品、近况、关于、搜索和关注；关于页减少重复故事。

## 本次不做

- 复杂标签筛选、知识图谱、引用悬浮预览或推荐算法。
- 评论系统重建、统一生成封面、装饰动画或整站技术栈迁移。
- 为所有旧文章补图、重写文章，或将各类内容统一改写成项目复盘。

## 验收

- 新文章发布后自动出现在首页最近更新；精选路径失效时构建失败。
- 首页精选与最近更新各有明确入口，作品的列表摘要来自该作品内容文件。
- 桌面和手机能访问工具成品、目录、体重图与结果摘要，页面无横向溢出。
- Hugo 构建、内容校验、内部链接检查和浏览器回归通过。

代码检查只能确认功能；陌生读者能否理解本站并找到想读的内容，仍需通过真实阅读反馈检验。
